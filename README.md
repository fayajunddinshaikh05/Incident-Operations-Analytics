# Incident Operations Analytics ⚙️

## Goal
Analyze system incidents to reduce downtime
and improve reliability using SQL, Python,
Power BI and AI-driven insights.

---

## Tools Used
| Tool | Purpose |
|------|---------|
| MySQL | Database and SQL queries |
| Python (Pandas) | MTTR, MTBF calculations |
| Power BI | Monitoring dashboard |
| ChatGPT | AI preventive actions |
| Excel | Data preparation |

---

## Skills Demonstrated
- SQL: Advanced aggregations, Time-based queries
- Python: MTTR, MTBF, Reliability calculations
- Power BI: KPI Dashboard, Charts, Slicers
- AI: Preventive action recommendations

---

## Dataset
- 200 system incidents
- Jan 2025 to Dec 2025
- 10 systems: Database, Web Server,
  Payment Gateway, API Gateway, etc.

---

## What I Did

### 1. SQL Analysis
- Monthly incident trend analysis
- SLA breach analysis by priority
- System wise performance analysis
- CTE with risk ranking
- Window functions for running totals

### 2. Python Analysis
- MTTR: 167.3 mins (2.79 hours)
- MTBF: 1.87 days
- Reliability: 93.8%
- System wise breakdown

### 3. Power BI Dashboard
- KPI Cards: Total Incidents, SLA Breach %,
  Avg MTTR, Critical Count
- Monthly trend line chart
- Priority distribution donut chart
- System wise bar charts
- Critical incidents detail table

### 4. AI Preventive Actions
- Used ChatGPT to identify root causes
- Generated preventive actions per system
- Timeline and ownership defined

---

## Key Findings
- Database has highest incidents: 28
- Payment Gateway has highest MTTR: 210 mins
- Overall reliability: 93.8% needs improvement
- Target reliability: 99.5%
